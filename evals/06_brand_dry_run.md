# 选到没有力气的时候，我只想把生活调回简单模式

装修以后才知道，做决定是会累的。

工长在那边等我确认插座的位置，手机上又弹出一条消息问柜门用什么颜色。瓷砖、灯、把手、柜门差的那两厘米，每一件单独看都不算大事，堆在一起却像从四面八方伸过来的手。那天从工地出来，我坐在车里很久没动，连晚饭吃什么都不想再选。

以前总觉得，选择越多越自由。后来才明白，不停地比较也是在消耗自己。那阵子我开始有意删掉一些不必要的选择，护肤也回到最简单的步骤。回家累到只想洗脸的时候，我用了 `[产品名]`。

`[补真实质地：例如轻薄、流动性如何]`，`[补真实使用步骤]`。`[补可验证的肤感或使用结果，不能写未经验证的功效]`。在 `[具体使用场景]` 里，它没有替我把生活整理好，但至少没有再多增加一道需要研究的选择。

生活真正需要的，也许不是更多可能性，而是知道哪些小事可以就此停下。
