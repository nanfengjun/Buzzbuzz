# Buzzbuzz 商业合作写作

## 一、识别规则

按用户确认的本地语料约定：**笔记标签中至少有一个明确品牌或具体产品名，就归为商业合作笔记**。正文中对平台账号的 `@` 不单独作为判定依据。

当前 222 篇语料中识别出 75 篇：

| 年份 | 商业合作笔记 |
|---|---:|
| 2022 | 2 |
| 2023 | 8 |
| 2024 | 13 |
| 2025 | 22 |
| 2026 | 30 |

完整清单由 `scripts/analyze_corpus.py` 自动生成在 `references/analysis/corpus-report.md` 的“商业合作笔记”一节。品牌标签只用于识别合作，不决定文章好坏，也不能反过来成为正文的写作提纲。

## 二、最重要的结论

她的高级软广不是“把商品藏在生活里”，而是：

> **先写一篇删掉产品也成立的文学性随笔，再让产品成为这篇随笔里的一个气味、触感、物件或生活动作。**

广告的主题不是产品，而是人：

- 她为什么疲惫、焦虑、犹豫或突然感到幸福；
- 她如何理解自由、关系、身体、时间与自我；
- 她正在过一种什么样的生活，审美和价值观如何安放。

产品不是这些主题的答案，只是主题落在日常里的一个细节。

## 三、比普通生活笔记更文学，但不更“文案腔”

商业合作笔记平均 832.2 字，普通笔记平均 639.8 字；中位数分别为 870 和 756 字。她为广告留出了更完整的叙事空间，但不是靠堆形容词变高级。

75 篇中，69 篇正文能直接检索到品牌或产品名。品牌首次出现位置为 18%-98%，P25 为 47%，中位 62%，P75 为 69%。没有任何一篇在正文前 15% 就出现明确品牌。

这不是要求机械延迟产品，而是说明成熟期合作通常会先让一个不依赖产品的人类母题成立。

成熟期广告通常多出以下层次：

1. **一个可独立成立的中心命题**：人不必过早介入宏大、友情不一定要 Happy ending、身体是精神的容器、焦虑是自由的眩晕。
2. **一个持续回返的意象系统**：水、雪、桂花、星星、房间、旧信、季节、旅行、时间。
3. **一段真正展开的个人经验**：起因、旧判断、具体场景、认知变化。
4. **产品所在的感官世界与前述意象相接**：木质调接稳定，桂花接秋天，香气接记忆，面霜接身体容器。
5. **产品只占很短的一段**：让读者知道她用了什么、感受是什么，但不把文章变成参数页。
6. **最后回到人的处境**：收尾仍能独立于产品阅读。

她很少突然切换成“专业测评口吻”。即使写到质地、香气、成分或使用步骤，也保持第一人称、场景和情绪连续。

## 四、成熟期广告的运作机制

### 1. 先有一个“去商品化”的论点

把品牌拿掉后，文章还必须有一个完整主题。

- 2026-10-14：真正累人的不是工作本身，而是每天没完没了的小决定。
- 2026-09-22：不再把 deep talk 当作亲密的唯一证明。
- 2026-09-14：秋天让人想带着已有的生命经验重新进入生活。
- 2026-08-21：明知无常仍认真投入生活，是一种“痴”。
- 2026-05-03：理解妈妈对自由的渴望，也是理解女性自己。
- 2026-04-15：看星星让人同时感到渺小和存在。

这些命题放在普通随笔里也成立。商业合作没有换掉文章的思考，只是多了一个品牌接口。

标题也要先去产品化。成熟期合作标题是 essay 标题，不是种草标题：

- 《用不一样的时间观察妈妈，也是一种女性主义》
- 《真正的少女心事是优绩主义下的自卑与自负》
- 《我们终于不再迷恋友情里的 Happy ending》
- 《不停做选择其实也是一种苦役》

标题中出现具体品牌或“必备、好物、种草、包里有什么”时，通常已经偏离成熟期写法。

### 2. 用感官语言把产品接入，而不是用卖点连接

她的产品段通常不写“所以我推荐”，而是写：

- 气味如何展开：前调、中调、尾调与一个场景或记忆对应；
- 触感如何发生：质地、温度、被包裹、贴肤、轻盈或沉稳；
- 动作如何嵌入生活：睡前涂抹、坐在桌前喝水、出门带伞、回家点香；
- 功能只保留理解场景需要的那一部分，不把所有参数排成清单。

产品体验与审美系统一致。香气可以接“记忆”“时间”“远方”，面霜可以接“身体的容器”“重新开始”，器物可以接“房间”“秩序”“照顾自己”。

### 3. 不主动推销，让产品在叙事里“自然发生”

产品出现方式多为：

- 日常习惯：一直在用的东西；
- 礼物：K 送的礼盒，物品承接关系；
- 记忆入口：闻到香气想起某段时间；
- 审美延续：文章本来就在谈秋天、木质、雨水、绿色；
- 生活动作：洗完澡、散完步、写完稿、准备睡觉时使用；
- 价值具象：清理旧物、认真吃饭、给未来托底。

即使产品在开头就出现，也不一定是“硬广”。例如 2025-08-06 的神仙水花束从 K 的礼物进入，整篇主线仍是“被看见的爱”，而非护肤功效。

但“可以早出现”不等于可以用产品品类制造开篇焦虑。产品可以是一份礼物、一个已经发生的动作，不能是文章需要解决的第一个问题。

### 4. 功能可以写，但不能成为论证骨架

她写过 PITERA™、蚕丝纤维结构、咖啡发酵滤液、护肤品提亮与修护等信息，但通常只有几句，且被放在情绪/感官段落内部。

判断标准不是“有没有写功效”，而是：

- 把功效句删掉，文章是否仍然是完整随笔？
- 功效是不是被夸成解决人生问题？
- 是否连续出现多个营销参数和购买指令？
- 是否为了产品卖点临时发明一个与全文无关的困境？

如果答案分别是“不是 / 是 / 是 / 是”，就已经偏离她的成熟期写法。

### 2023：问题—方法—产品

早期仍有明显经验帖结构，产品承担实际解决方案，使用场景和功效说明更直接。

- 2023-09-07：干眼症护眼方法中提到好医保门诊险的价格优势。
- 2023-11-06：波士顿换季 routine 中写国际集运体验与活动。
- 2024-05-02：生活秩序 essay 中写茶派的具体饮用场景。
- 2024-06-07：学习压力 essay 中展开蚕丝被的透气和睡眠体验。

这一阶段可以作为“方法型合作”参考，但不能当作成熟期高级软广的最高标准。

## 五之二、护舒宝与 ABC：两种可接受的卫生用品入口

### 护舒宝：先写母女关系，再让产品作为照护的物证

2025-06-07《用不一样的时间观察妈妈，也是一种女性主义》：

1. 第一段写“我和妈妈是比网上讨论的‘东亚母女’更潮湿复杂的关系”。
2. 接着写自己曾用女性主义审视妈妈，年长后发现彼此越来越像。
3. 直到约 38%-44% 才写到妈妈记得自己的经期和生理痛。
4. 妈妈递来一袋卫生巾，说自己已经不来月经了；产品成为母女照护与女性生命阶段的物证。
5. 护舒宝约在 50% 出现；先写蓝色盒子和“妈妈与我的潮汐”，再写少量液体卫生巾体验。
6. 结尾回到妈妈那一代如何理解女性主义，产品彻底退场。

这篇文章没有用“包里有没有卫生巾”“突然来月经怎么办”开场。它先处理的是两代女性如何彼此理解。

### ABC：月经可以较早出现，但必须属于一个更大的女性问题

2026-09-29《真正的少女心事是优绩主义下的自卑与自负。》：

1. 开头是崔恩荣小说里的场景：女生因经血渗出牛仔裤不敢起身。
2. 随即回到高三：自己答对难题却没有站起来，因为月经和裤子可能弄脏。
3. 命题是女性学习、工作和公开发言时，身体局促如何夺走注意力。
4. ABC 直到约 68% 才出现。
5. 结尾希望每个女性下次都能毫不犹豫地站起来。

这篇的月经是文学与女性处境的一部分，不是产品购买的焦虑入口。品牌仍然远晚于人的问题。

### 核心区分

| 可以出现的开头 | 不应出现的开头 |
|---|---|
| 母女关系与代际女性经验 | “包里有没有卫生巾” |
| 文学中的身体羞耻场景 | “突然来月经怎么办” |
| 一次因为身体而放弃发言的经历 | “经期必备好物” |
| 女性友谊中的互助 | 把卫生巾和钥匙、雨伞并列为成年人安全感清单 |

| 产品类型 | 先写什么 | 产品如何进入 |
|---|---|---|
| 卫生巾 / 女性护理 | 母女、女性发言、身体羞耻、朋友互助 | 被递来、被分享、帮助注意回到事情本身 |
| 护肤 / 美妆 | 疲惫、身体容器、季节转换、自我照料 | 睡前动作、换季习惯、礼物 |

## 六、写作流程

### Step 1：把 brief 放在一边，先找文章母题

用一句话回答：

> 如果这个产品不存在，我仍然想借今天的经历讨论什么？

合格母题必须能脱离产品成立。例如：

- 休息不是另一种绩效；
- 爱不需要用讨好证明；
- 成长不是不停找新标签解释自己；
- 选择越多不等于越自由；
- 身体先于精神感受到生活的重量。

还要先写一个**去产品化的标题**。标题应在品牌不存在时也像一篇她会发的随笔，而不是“产品 + 场景 + 好处”。

### Step 2：找产品与母题之间的唯一主桥

只选一个桥，不要把所有卖点都连上：

- 气味 ↔ 记忆 / 时间；
- 触感 ↔ 安全感 / 被接住；
- 器物 ↔ 房间 / 日常秩序；
- 使用动作 ↔ 停下来 / 照顾自己；
- 服务动作 ↔ 城市中的脆弱 / 流动性；
- 功能事实 ↔ 身体处境，且必须克制。

桥必须来自真实生活，不可以为了产品临时编造一段重大创伤或关系事件。

对卫生用品、医疗、金融等敏感或功能强的品类，先选择人的入口：

- 关系：妈妈、朋友、伴侣、过去的自己；
- 身体：羞耻、疼痛、局促、成长、衰老；
- 社会处境：公开发言、工作、学习、行动自由；
- 文化文本：文学、电影、访谈；
- 通过标准：产品品类不是第一段的主要问题。

### Step 3：先写完散文，再插入产品

**先在不写品牌、不写产品的前提下完成一版完整随笔。** 再插入：

1. 具体场景；
2. 旧判断；
3. 经验转折；
4. 更大的主题；
5. 不用产品的结尾。

找到产品最适合进入的“感知位置”后，用 2-4 个自然段完成：

- 产品如何出现；
- 一个真实动作；
- 一个感官细节；
- 一条必要且可验证的功能信息；
- 它如何延续而不是抢走前文主题。

默认让品牌在正文 40% 之后才出现；语料中位数约 62%。只有在第一段已经有礼物、人物动作或完整关系事件时，才允许更早出现。

### Step 4：做“删除测试”

删去产品名和功能句，再读全文：

- 若文章完全断裂，说明产品仍在承重，商业感会重；
- 若文章仍成立，但少了一个具体的生活触点，通常是合适的比例；
- 若产品段可以整段移到任意其他文章，说明连接太弱，要重写桥梁。

### Step 5：做广告透明度检查

- 用户真实用过，才写第一人称体验；
- 产品功能以 brief、包装或可验证资料为准；
- 合作标签、平台合作标识和必要的商业披露保留；
- 不把未证实的效果写成个人确定经验；
- 医疗、金融和身体护理尤其避免绝对化承诺。

## 七、商业合作的默认输出结构

### 成熟期版本（默认）

1. **去产品化标题**：先是一个可独立成立的 essay 命题。
2. **人的开场**：关系、经验、文学、身体处境、季节或一个明确判断。
3. **母题展开**：不出现产品品类焦虑，不把产品当作文章的起始问题。
4. **认知/情绪转折**：写出为什么这个主题值得被讲。
5. **产品被具体动作引入**：递来、收到、打开、使用、分享。
6. **克制的产品体验**：2-4 段，必要信息即可。
7. **产品退场**：回到人的命题，不以产品好处收尾。

产品出现可以早，也可以接近结尾。位置服从叙事，不服从固定比例。

### 早期方法型版本（仅当用户要教程/清单）

1. 真实问题与使用背景；
2. 两三个可执行方法；
3. 产品只负责其中一个具体环节；
4. 明确适用边界；
5. 返回生活判断。

## 八、反面示例

### 失败模式：用产品品类制造开头焦虑

以下是一个“语言还算自然、结构仍不合格”的卫生巾广告开头：

> 有段时间，我出门前总会多问自己一句：包里还有卫生巾吗？

问题不在句子不美，而在它一开场就把文章变成产品使用焦虑：

- 标题围绕“包里那一小格”；
- 第一句直接提到卫生巾；
- 前文把卫生巾与钥匙、充电宝、雨伞并列；
- 整篇的核心是“有没有带”；
- 产品成为安全感的来源；
- 结尾“少问自己一遍”再次回收产品利益。

这仍是高级一些的生活小妙招，不是博主的成熟期广告。

测试稿的品牌名约在正文 45% 处才出现，表面上落在成熟期语料的常见区间；但产品品类在 5% 就出现，整篇文章的第一问题仍是“有没有带卫生巾”。**产品晚出现不等于广告高级。位置不是核心，产品出现前是什么母题才是。**

**改写方向不是把“卫生巾”换成别的词，而是换掉文章骨架。** 先找到母爱、女性发言、身体羞耻、朋友互助或生命阶段变化中的真实经历，再让卫生巾在那个经历里出现。

不要把成熟期广告写成：

> 最近加班太累了，皮肤也很差。直到我用了 XX，核心成分能快速修护屏障，提亮肤色，第二天状态满分。姐妹们真的闭眼冲！

问题不是出现产品，而是：

- 困境成了一句套话；
- 产品被写成解决问题的英雄；
- 功效清单抢走叙事；
- 最后一句转为叫卖；
- 换成任何品牌都能成立。

更接近她的机制是：

- 先写一个只属于这篇文章的生活经验；
- 让审美、情绪、身体和产品感官处在同一套语言里；
- 只保留必要产品事实；
- 产品退场后，文章仍有一句真正的结尾。

## 九、品牌合作生成时的事实纪律

如果用户只给“产品名 + brief”，没有真实生活素材：

1. 不能伪造她收到礼物、长期使用、旅行经历或身体变化；
2. 先用 `[真实场景]`、`[真实使用动作]`、`[可验证体验]` 做少量占位；
3. 正文结构按她的商业写法完成；
4. 在正文后最多列 3 条发布前必须替换的信息；
5. 商业标签和合作标识不能被文学化处理掉。

如果用户要直接可发布的成熟期广告，而完全没有真实入口，应先问一个短问题：想从家人/朋友、校园或工作、身体经历、文学或旅行中的哪一个具体场景进入。不要自行补造“忘了带”“突然发生”“今天终于用了”的通用故事。

高保真不等于高欺骗性。越像她，越需要保留真实经验与广告关系的边界。
